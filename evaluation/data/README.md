# Local evaluation data

Model files and all derived model files are excluded from publication. Obtain
and export the models using the instructions in [../README.md](../README.md),
then save the original XMI exports in `evaluation/data/xmi/`.

The preparation pipeline creates the JSON and reconstructed XMI subdirectories
here. Raw LLM responses are also saved here, in `llm_results/`. Everything under
this directory except this README is ignored by Git.
